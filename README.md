# fullbright-1.21.11 (Phantom Spawner)

Клавиша P (меняется в Настройки -> Управление) открывает меню:
координаты X/Y/Z (или кнопка "Моя позиция"), поиск и выбор моба, кнопки "Создать"/"Удалить".
Нужны права оператора. Мод ставится и на клиент, и на сервер (+ Fabric API).

## Как получить .jar
Вариант 1 (без установки): залей папку на GitHub -> вкладка Actions -> build -> Artifacts -> phantomspawner-jar.
Вариант 2 (локально): установи JDK 21 и Gradle 8.14+, затем в папке проекта: `gradle build`.
Файл появится в build/libs/ (fullbright-1.21.11.jar) (бери тот, у которого нет -sources).
